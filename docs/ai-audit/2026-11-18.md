# Compact drawing compiler increment — 2026-11-18

Continued from the November 17 audit. The usage-limit interruption had saved no
compiler code. Existing staged/unstaged editor fixes were preserved.

## Implemented

- A model-chosen compact response alongside the existing native operation path.
  Named parts, shared normalized coordinate system, relative parent placement,
  ellipses/rectangles/triangles and open/closed smooth brush paths.
- A deterministic TypeScript compiler into existing native shapes, brushes and
  keyframes. No subject names, subject geometry, image assets or prompt routing
  in the compiler; no new renderer or document model.
- Shared-pivot rotation, translation and uniform scale, including nested parents.
  The compiler composes transforms and adaptively samples native tracks; it
  preserves authored key times, omits constant tracks and respects 64 keys/track.
- Geometry validation before the native dry application: invalid/forward parents,
  duplicate names, empty groups, unknown fields, paint, dimensions, degenerate
  or self-crossing control polygons, off-canvas sampled bounds and invalid/no-op
  animation. Rotating an isolated unmarked circle is rejected as invisible motion.
- Native text and existing-layer operations remain available directly. There is
  no new planning inference. The existing client correction/inspection limits
  were not increased.
- Primitive-specific decoding requires path points and closure. Point generation
  uses a .05 grid because the real model emitted negative points despite float
  min/max bounds. The compiler accepts arbitrary in-range precision. Instructions
  now separate native pixel units from compact square units, put parent choice
  before coordinates, and request minified JSON.

Schema and exact limits: [AI_DRAWING_PROTOCOL.md](../AI_DRAWING_PROTOCOL.md).

model selection and route. Exact new prompt:

Previous audit prompt included “cat face”; therefore this is a close comparison,
not an identical-prompt benchmark. Previous result: 795 output tokens, 278.2s,

These failures led to the final instruction/decoder revision described above.
The final probe explicitly disables a correction call **in the test harness** so

## Remaining architectural limits

This compiler does not recognize a cat or judge anatomy. Valid geometry can still
be an incorrect drawing. Part names identify relationships; native layers receive
the editor's usual UUIDs. Groups are baked into independent layer keyframes and
do not become persistent manually editable groups. Sampling uses a half-pixel
midpoint error target, not a continuous-time mathematical bound. Bounds are
conservative and sampled; intentional off-canvas movement is outside this
prototype. Native text plus compact parts cannot be mixed in one response yet.
No FFmpeg fallback rewrite or cloud-save roundtrip is claimed.

### Last decoder revision and verification boundary

The saved implementation now asks for `mode:edit` or `mode:draw` **before** the
version, summary and payload. This addresses early grammar-branch selection;
it is not subject-specific routing. The adapter removes edit mode before normal
native validation, or compiles draw mode before the same validation/application.
Tests check both modes and reject a mismatched native mode. Old mode-less payloads
remain readable.

**No real Qwen request has been benchmarked against this final explicit-mode
revision.** Its parsing and browser integration are verified; improved model
choice, recognition and speed are unverified. The user requested no further slow
cat retries, so verification stops here without a drawing-success claim.

## Keep/release assessment and exact change scope

Safe to keep as a validated **experimental compiler increment**, subject to the
limits above. No tested canvas, native animation, timeline application, undo/redo
or WebCodecs regression was found. Existing-layer validation tests also pass.
This does not certify every editor feature, browser, FFmpeg fallback or cloud-save
roundtrip. The temporary native-text inference regression is documented above;
final explicit-mode model behavior is not proven fixed by replay tests.

**Creative drawing remains unreliable and is not production-ready.** Structural
validation cannot detect that `HAHA` is not a cat. Invalid geometry is rejected
before application, but semantically wrong valid content can still be applied.
No hardcoded subjects, extra inference stages, dependencies, renderer types or
persistent groups were added. The existing single correction/capability lookup
limits were preserved. The 20-second quality target was not achieved.
